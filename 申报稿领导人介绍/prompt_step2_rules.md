根据以下已提取的表格数据，生成领导人信息JSON。

## 长文本通用清洗规则
- 去空格，英文人名、公司名、地名等专有名词内部的空格必须保留（如 "John Smith" → "John Smith"，"New York Times" → "New York Times"，"Apple Inc." → "Apple Inc."）
- 以下所有中文符号替换为对应英文符号：
  - ， → ,
  - ； → ;
  - ： → :
  - ‘’ → '
  - “” → "
  - （ → (
  - ） → )
  - ？ → ?

## 职位提取规则
### 董事会（BOARD段）
- 从"职务"列提取职位
- 职务含"董事长"或"副董事长"→ 追加"董事"
  例："董事长、总经理"→"董事长、总经理、董事"
- "独立董事"→"独立董事"（不追加"董事"）

### 高级管理人员（EXECUTIVES段）
- 从"职务"列提取具体职务
- ⚠️ "高级管理人员"是章节名，不是职务。如"财务负责人"→只输出"财务负责人"

### 核心技术人员（CORE_TECH段）
- 段中列出的所有人 → 追加"核心技术人员"

### 专门委员会（SPECIAL_COMMITTEES段）
- 逐委员会处理："主任委员"→"XXX委员会主任委员"，"召集人"→"XXX委员会召集人"，"成员"列每人都获得"XXX委员会成员"，"委员"→"XXX委员会委员"
- "主任委员"和"召集人"同义，"成员"和"委员"同义，根据实际情况选择输出
- 同一人在不同委员会可有不同角色，都要输出
- 4个委员会全部处理完毕后，按人汇总

### 合并职位
- 汇总以上所有来源的职位，去重，用顿号连接。
- 排序：董事类→高管类→委员会类→核心技术人员。

## 其他字段规则
### 性别
- 简历或称谓中"先生/男"→"男"，"女士/女"→"女"，无则""

### 国籍
- "中国国籍/中国人/党员/中国党员" → "中国"
- "美国国籍"、"美国人" → "美国"
- 永久居留权≠国籍，无则""

### 职称（仅限词库）
工程师、高级工程师、助理工程师、经济师、高级经济师、助理经济师、研究员、副研究员、助理研究员、院士、教授、副教授、政工师、高级政工师、助理政工师、会计师、高级会计师、注册会计师、审计师、高级审计师、注册审计师、注册税务师、注册评估师、执业药师、建筑师、分析师、测量师、律师
- ⚠️ 公司职务不是职称，禁止混入。只输出词库内匹配的职称。

### 出生日期
- "1980年1月1日"→"1980-01-01"，"1973年1月出生"→"1973-01"；无则""

### 学历
- 博士>硕士>本科>大专>高中>中专>初中及以下>其他，在读降一级，"研究生"→"硕士"
- **“博士生导师”、“毕业于大学或学院”、“XX专业”等描述不参与学历判断**
- 若简历中没有学历信息，输出""

### 任期上限
- 领导人的任职开始日期，YYYY-MM-DD，仅到月则当月第一天，无则""
- 例：“2024年2月-2027年2月” → “2024-02-01”

### 兼职
- 其他公司在任的兼职，无则""

### 背景介绍
- RESUMES段中该人的简历，一般是“姓名，性别，出生日期……”开头，按照原文内容输出，无则""
- 按长文本通用清洗规则处理格式，去除文字间多余空格，保留英文间的空格

### 本公司
文件标题中的公司全称

## 核心禁止
- 禁止从简历提取职位（简历仅用于背景介绍和其他字段）
- 禁止"高级管理人员"作为职位
- 禁止同一人同一委员会两种角色，如果在同一委员会同时担任"主任委员/召集人"和"委员/成员"，则输出"XXX委员会主任委员"或"XXX委员会召集人"
- 禁止为缺失字段生成不存在的内容
- 禁止输出职称词库外的职称

## 最终自检
1. 逐人检查：有无简历中的职务混入？委员会职位是否完整或缺失（4个委员会都检查）？有无"高级管理人员"误输出？
2. 职称是否匹配词库内职称？
3. 性别、出生日期、学历、国籍是否匹配？
4. 背景介绍是否按照长文本通用格式处理？
