# 委员会切片处理功能实现计划

## 需求分析

### 现有功能
- 董监高人员情况的切片处理（从前往后搜索）

### 新增功能
- 委员会切片处理（从后往前搜索）

### 委员会处理逻辑

#### 根据交易所类型区分处理

**北交所 (bjs)**：
- 开始关键词：`"运行情况"`
- 正则匹配：`委员会.*建立健全及运行情况\s*$`
- 查找范围：从后第150页开始往前查找

**其他交易所 (szs/cyb/shs/kcb)**：
- 开始关键词：`"设置情况说明"`
- 正则匹配：`委员会.*设置情况说明\s*$`
- 查找范围：从最后一页开始往前查找

#### 通用处理逻辑
1. **搜索方向**：从后往前逐页查询
2. **正则匹配**：根据交易所类型使用对应正则
3. **结束判断逻辑**：
   - 查询到开始关键词后，截取当页开始关键词及以下位置
   - 从开始关键词页后一页开始查询是否包含"委员会"关键词
   - 如果包含且第一个出现位置在页面30%以上，则完整输出该页，继续查询下一页
   - 如果不包含或位置在30%以下，则结束查询
4. **输出**：将委员会内容拼接在董监高人员情况内容后一起输出

## 实现步骤

### 步骤1：新增委员会关键词查找逻辑
在 `find_keywords()` 函数中新增委员会相关逻辑：
- 根据交易所类型设置不同的正则和关键词
- 实现从后往前的搜索逻辑
- 返回委员会开始页信息

### 步骤2：新增委员会后续页面判断函数
新增 `find_committee_additional_pages()` 函数：
- 从开始关键词页后一页开始，逐页检查是否包含"委员会"关键词
- 检查"委员会"出现位置是否在页面30%以上
- 返回需要完整输出的后续页面号列表

### 步骤3：修改 process_pdf 函数
- 在处理完董监高人员情况后，调用委员会处理逻辑
- 将委员会页面拼接在董监高人员情况页面后
- 统一输出到同一个PDF文件

### 2. 委员会后续页面判断函数

```python
def find_committee_additional_pages(pdf_path, start_page_number):
    """
    从委员会开始页后一页开始，判断后续页面是否需要输出
    
    判断逻辑：
    1. 只检查开始关键词页的后一页
    2. 查询页面是否包含"委员会"关键词
    3. 如果包含，检查第一个出现位置是否在页面30%以上（y0 < page_height * 0.3）
    4. 满足条件则完整输出该页
    5. 不满足条件则不输出该页
    
    参数:
        pdf_path: PDF文件路径
        start_page_number: 委员会开始页码（1-based）
    
    返回:
        list: 需要完整输出的后续页面号列表（1-based），最多1页
    """
    doc = fitz.open(pdf_path)
    total_pages = len(doc)
    additional_pages = []
    
    # 只检查开始页后一页
    if start_page_number < total_pages:
        page_num = start_page_number  # 0-based index
        page = doc.load_page(page_num)
        page_height = page.rect.height
        
        # 搜索"委员会"关键词
        instances = page.search_for("委员会")
        
        if instances:
            # 检查第一个出现位置是否在页面30%以上
            first_instance = instances[0]
            if first_instance.y0 < page_height * 0.3:
                # 位置在30%以上，完整输出该页
                additional_pages.append(page_num + 1)
    
    doc.close()
    return additional_pages
```

**输出规则**：
- 最多输出：关键词页 + 后一页（共2页）
- 至少输出：关键词页（1页）
- 未找到关键词：不输出委员会页

### 4. 完整的 process_pdf() 修改

```python
def process_pdf(pdf_path, keywords, output_dir):
    """通用PDF处理函数，处理交易所PDF"""
    start_info = keywords.get('start')
    end_info = keywords.get('end')
    committee_info = keywords.get('committee')
    
    # ... 现有的董监高处理逻辑 ...
    
    try:
        reader = PdfReader(pdf_path)
        writer = PdfWriter()
        
        # 1. 处理董监高人员情况
        if start_info and end_info:
            for page_num in range(start_info['page_number'] - 1, end_info['page_number']):
                page = reader.pages[page_num]
                
                if page_num == start_info['page_number'] - 1:
                    cropped_page = crop_page_with_rotation(page, start_info, 'bottom')
                    writer.add_page(cropped_page)
                elif page_num == end_info['page_number'] - 1:
                    cropped_page = crop_page_with_rotation(page, end_info, 'top')
                    writer.add_page(cropped_page)
                else:
                    writer.add_page(page)
        
        # 2. 处理委员会（如果找到则拼接到董监高后面，否则跳过）
        if committee_info:
            print(f"找到委员会信息，开始处理...")
            committee_page_num = committee_info['page_number'] - 1
            page = reader.pages[committee_page_num]
            
            # 裁剪开始关键词及以下位置
            cropped_page = crop_page_with_rotation(page, committee_info, 'bottom')
            writer.add_page(cropped_page)
            
            # 获取并添加后续页面
            additional_pages = find_committee_additional_pages(pdf_path, committee_info['page_number'])
            for page_num in additional_pages:
                page = reader.pages[page_num - 1]
                writer.add_page(page)
        else:
            print(f"未找到委员会信息，跳过委员会处理")
        
        # 输出PDF
        base_name = os.path.splitext(os.path.basename(pdf_path))[0]
        os.makedirs(output_dir, exist_ok=True)
        output_path = os.path.join(output_dir, f"{base_name}.pdf")
        
        with open(output_path, "wb") as output_file:
            writer.write(output_file)
        
        print(f"已处理并保存到: {output_path}")
        return output_path
```

**注意**：如果 `committee_info` 为 `None`（未找到委员会信息），则跳过委员会处理，正常输出董监高人员情况切片。
